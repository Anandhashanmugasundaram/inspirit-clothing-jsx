# INSPIRIT CLOTHING

Premium luxury streetwear ecommerce frontend.

## Stack
- React 18 + Vite (JSX)
- React Router DOM v6
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Swiper, Lenis, React Hot Toast, React Icons, Axios
- Context API for cart/wishlist/auth

## Run
```bash
npm install     # or: bun install
npm run dev
```

Open http://localhost:5173

## Build
```bash
npm run build
npm run preview
```
